## 👋 About this portfolio

**Prithvi's Portfolio** is a neo-classic, Greek-inspired personal website built by **Prithviraj A Bhori** — a frontend engineer and UI/UX designer who likes turning complex design requirements into clean, maintainable code.

It's part portfolio, part design-system playground: tactile components, Material-style elevation, editorial typography, and subtle motion throughout.

> *"Crafting interfaces where structure meets soul."*

---

## ✨ Highlights

- **Neo-classic visual language** — Playfair Display headings, Inter body copy, gold/teal accents, meander borders and column lines.
- **Fully responsive** — carefully tuned from 320px phones through tablets to wide desktop screens.
- **Interactive design system** — toggles, floating-label inputs, chips, elevation layers, ratings and color palette in *The Artifacts*.
- **Case studies** — Secure Print, Movie Database, Online Voting System and Blood Bank Management in *The Pillars*.
- **Training & timeline** — MERN Stack training at Pentagon Space, internships and education presented as a cinematic archive.
- **A secret-ish page** — *Beyond Code*, a dedicated route with a cinematic "page is in progress" title card.

## 🚀 Deploy to Vercel

This project is preconfigured for Vercel via `vercel.json`.

### Option A — Git integration (recommended)

1. Push the project to GitHub/GitLab/Bitbucket.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Vercel detects the **Vite** preset automatically. Confirm these settings:
   - **Build command:** `npm run build:vercel`
   - **Output directory:** `dist`
   - **Install command:** `npm install`
4. Click **Deploy**. Every push to the default branch then deploys automatically.

### Option B — Vercel CLI

```bash
# install the CLI once
npm install -g vercel

# preview deployment
vercel

# production deployment
vercel --prod
```

> `npm run build:vercel` runs `vite build --base=/`, which overrides the GitHub Pages subpath base (`/Portfolio/`) so asset URLs resolve correctly on a Vercel root domain. Client-side routes such as `/beyond-code` are handled by the SPA rewrite in `vercel.json`.

GitHub Pages still works unchanged with `npm run deploy`.
